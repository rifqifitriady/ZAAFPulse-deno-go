- **Found and fixed (D25):** with every go call sending two spans, the control plane wrote the trace store once per
  span; at 200–500 streams it fell behind (the 200-stream step lost 200 streams to a gateway restart, the 500-stream
  overhead p95 reached 505 ms). The ingest now buffers the spans and writes them in one call before each ack, as the
  JS recorder batches its own: the stream steps are back to the tracing-off numbers.
- M3 (p95 ≤ 2.84 ms) and M4 (500 streams overhead p95 ≤ 10 ms) are not met on this machine by the base either; P4f
  with D25 is within noise of the base (non-stream p95 +0.66 ms; 500-stream overhead p95 +17 ms, the same as with
  tracing off, so not the spans). The 50-stream 103.57 ms is one noisy step (the direct side completed 961 of 1000).
- M4 gateway RSS ≤ 80 MB: met (71 MB peak).
- A quiet-machine run on power is left for the program's final benchmarks (see the deferred list).
