# P4c Streaming Chat Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Streaming `POST /v1/chat/completions` to OpenAI-format providers can run on the Go engine (`zaafpulse-gw`) behind its own shadow gate, byte-identical to the JS gateway's stream, with exactly one usage line per stream, and M4 met at 500 concurrent streams.

**Architecture:** The P4b go engine gains a sub-class `chat-stream` that it picks after reading the body. A served stream calls the provider with P4b's upstream client up to the headers (`Upstream.Start`), then copies the provider's body to the client through `ChatStream`, a byte-exact port of `chatCompletion`'s line rewriter (`gw/engine/stream.go`), flushing after each provider read and writing synchronously (natural backpressure). The usage line (last usage chunk, time to first token, cost) is emitted once, after the stream ends for any reason, through the outbox. While `chat-stream` is on js and shadowed, the control plane serves the stream and keeps a capture of the provider's text and its own client text; the engine replays the captured provider text through `ChatStream` and compares. `bench/run.js` measures M4 (and M3 again) with the go engine serving.

**Tech Stack:** Go 1.27.3 standard library only (`net/http`, `http.ResponseController`, `sync`, `unicode/utf8`), Deno 2.9.8 and Node 24 (CI 24.21.0), CommonJS, `node:test`, `AsyncLocalStorage`, IPC v1, GitHub Actions, prettier 3 (printWidth 120) on clean JS files, `gofmt`.

## Decisions

The spec's Decisions 1–16 hold; each one line here, with the task that builds it.

1. First streaming class: OpenAI-format chat pass-through on the P4b serving set, no translation (Task 1, Task 2).
2. Streaming has its own sub-class `chat-stream` with its own engine entry, shadow entry and switch-rule record (Task 3).
3. The front hands `chat` to the engine when either sub-class is on go or shadowed; the engine picks the sub-class from the body (Task 3).
4. The rewriter is a port of `chatCompletion`'s `line()`, not `readSse`, checked against JS fixtures (Task 1).
5. `stream_options.include_usage: true` is added upstream as `proxyChat` adds it (`streamUsage` preset flag); a non-object `stream_options` that JavaScript would spread into indexed keys is handed off (Task 1).
6. Exactly one usage line per stream, emitted off the client's path, awaited at shutdown before the outbox closes (Task 2).
7. Client abort cancels the provider call; a provider cut ends the client's response cleanly; both write one line (Task 2, Task 3).
8. Flush after each provider read; headers flushed when the provider's 2xx arrives (Task 2).
9. No heartbeat on chat, 120 s to the provider's headers, no body or write timeout (Task 2).
10. Synchronous writes give backpressure instead of Node's unbounded buffering (Task 2).
11. Memory budget: 4 KiB read buffer, no line buffer held between events, request bodies released once sent, 1 KiB upstream write buffer, 16 MiB line cap; ≤ 80 KiB per held stream (Task 2; Decision 19).
12. Shadow from one provider call: the control plane captures the provider text and its client text; the engine replays (Task 5).
13. Hand-off order: P4b hand-offs, then a non-object `stream_options`, then the `chat-stream` mode (Task 1, Task 3).
14. M4 (and M3 again) measured with `bench/run.js`, private tier, gateway RSS from its own pid, engine use counted at the mock (Task 4).
15. Windows: same path, CI-proven, not benchmarked (Task 6).
16. A gateway crash loses the line of in-flight go streams (never doubles it): known gap, owner question 2 (Task 3 kill test, Task 7 results).

**Plan decision P1 (order):** the risky parts come first. Task 1 (byte exactness) and Task 2 (serving, exactly-once, memory and a 200-stream in-process load) are the foundations; **Task 4 (M4 on the real product) runs before the shadow work (Task 5)**, so a performance miss is found while the design can still change. Task 2 ends with a gate: if the per-stream memory test is over budget or the 200-stream test fails, stop and report before Task 3.

**Plan decision P2 (what is shown in full):** code is shown in full where it is new and self-contained (`stream.go`, the stream tests, `Upstream.Start`, `onceBody`, the stream serve loop, the bench knobs, the JS capture). Where a step edits P4b code that may still move (`PlanChat`, `Serve`, `Shadow`, the front's dispatch, `routing()`, the shutdown order), the step shows the intended code and is marked **re-check against the merged P4b**.

```go
package engine

// The streaming chat route on the go engine (P4c, slice S3): lib/gateway/index.js chatCompletion's stream branch for an
// OpenAI-format provider. The provider's stream is split into lines on the byte \n (never part of a UTF-8 sequence) and
// each line is rewritten as chatCompletion's line() does: a data: line holding a JSON object or array is written again
// with the requested model name; without the client's include_usage, a usage-only chunk is dropped with the blank line
// after it and "usage": null is removed; every other line passes as it came, its \r dropped. Usage and the time to the
// first token are read on the way. The output does not depend on how the provider's bytes were split into reads.

import (
	"bytes"
	"errors"
	"strings"
	"unicode/utf8"
)

// MaxStreamLine: a provider line longer than this ends the stream as a cut does (chatCompletion has no limit).
const MaxStreamLine = 16 << 20

// ErrStreamLine is Feed's error for a line longer than MaxStreamLine.
var ErrStreamLine = errors.New("engine: a provider stream line is longer than 16 MiB")

var utf8BOM = []byte{0xef, 0xbb, 0xbf}

// ChatStream rewrites one provider stream for the client.
type ChatStream struct {
	model      string
	wantsUsage bool
	elapsed    func() float64
	buf        []byte // the bytes of a line not yet complete
	bomDone    bool
	skipBlank  bool

	TTFT                  *float64 // ms from the call's start to the first content or tool-call delta
	Input, Output, Cached int64    // the last usage chunk's tokens (tokens(): 0 when not a whole number)
	Unsupported           int      // data: lines JSON.parse reads and this engine does not (passed unchanged)
}

// NewChatStream starts a stream for the client's requested model name; wantsUsage is the client's
// stream_options.include_usage; elapsed gives ms since the call's start.
func NewChatStream(model string, wantsUsage bool, elapsed func() float64) *ChatStream {
	return &ChatStream{model: model, wantsUsage: wantsUsage, elapsed: elapsed}
}

// Feed takes the provider's next bytes and returns what the client gets now (nil: nothing yet).
func (s *ChatStream) Feed(p []byte) ([]byte, error) {
	s.buf = append(s.buf, p...)
	if !s.bomDone {
		// TextDecoder drops one byte order mark at the start of the stream, also when it arrives in pieces.
		if len(s.buf) < len(utf8BOM) && bytes.HasPrefix(utf8BOM, s.buf) {
			return nil, nil
		}
		s.buf = bytes.TrimPrefix(s.buf, utf8BOM)
		s.bomDone = true
	}
	var out []byte
	start := 0
	for {
		nl := bytes.IndexByte(s.buf[start:], '\n')
		if nl < 0 {
			break
		}
		raw := s.buf[start : start+nl]
		start += nl + 1
		if s.skipBlank && jsBlank(raw) {
			s.skipBlank = false
			continue
		}
		s.skipBlank = false
		if w, keep := s.line(raw); keep {
			out = append(out, w...)
		} else {
			s.skipBlank = true
		}
	}
	rest := len(s.buf) - start
	if rest > MaxStreamLine {
		return out, ErrStreamLine
	}
	if cap(s.buf) > 64<<10 && rest < 4<<10 {
		s.buf = append([]byte(nil), s.buf[start:]...) // let a big line's buffer go
	} else {
		s.buf = append(s.buf[:0], s.buf[start:]...)
	}
	return out, nil
}

// End is the provider's clean end: the last line if it had no \n, rewritten with one (chatCompletion's
// `if (buf) res.write(line(buf) || '')`). Not called after a cut, which writes no partial line.
func (s *ChatStream) End() []byte {
	if !s.bomDone {
		return nil // at most a partial byte order mark, which TextDecoder holds and never flushes
	}
	rest := s.buf[:len(s.buf)-incompleteTail(s.buf)]
	s.buf = nil
	if len(rest) == 0 {
		return nil
	}
	if w, keep := s.line(rest); keep {
		return w
	}
	return nil
}

// line is chatCompletion's line(): the bytes for the client and true, or false for a dropped usage-only chunk.
func (s *ChatStream) line(raw []byte) ([]byte, bool) {
	raw = bytes.TrimSuffix(raw, []byte{'\r'})
	text := validText(raw)
	pass := func() ([]byte, bool) { return append([]byte(text), '\n'), true }
	// "data: [DONE]" needs no test of its own: JSON.parse("[DONE]") throws, and that passes the line as it is too.
	if !strings.HasPrefix(text, "data:") {
		return pass()
	}
	c, err := Parse([]byte(text[5:]))
	if err != nil {
		if errors.Is(err, ErrUnsupported) {
			s.Unsupported++
		}
		return pass()
	}
	if c.Kind != Object && c.Kind != Array {
		return pass()
	}
	d := firstElem(c.Get("choices")).Get("delta")
	if s.TTFT == nil && d.Truthy() && (d.Get("content").Truthy() || d.Get("tool_calls").Truthy()) {
		t := s.elapsed()
		s.TTFT = &t
	}
	if c.Get("usage").Truthy() {
		s.Input, s.Output, s.Cached = tokens(c)
	}
	if !s.wantsUsage {
		ch := c.Get("choices")
		if ch != nil && ch.Kind == Array && len(ch.A) == 0 && c.Get("usage").Truthy() && !c.Get("error").Truthy() {
			return nil, false
		}
		if u := c.Get("usage"); u != nil && u.Kind == Null {
			c.Delete("usage")
		}
	}
	if m := c.Get("model"); m != nil && m.Kind == String {
		c.Set("model", Str(s.model))
	}
	return append(append([]byte("data: "), c.Stringify()...), '\n'), true
}

// firstElem is `c.choices && c.choices[0]`: an array's first element or an object's key "0".
func firstElem(v *Value) *Value {
	if !v.Truthy() {
		return nil
	}
	switch v.Kind {
	case Array:
		if len(v.A) > 0 {
			return v.A[0]
		}
	case Object:
		return v.Get("0")
	}
	return nil
}

// validText decodes a line: each run of invalid bytes becomes one U+FFFD (P4b difference 9).
func validText(b []byte) string {
	if utf8.Valid(b) {
		return string(b)
	}
	return strings.ToValidUTF8(string(b), "\uFFFD")
}

// jsBlank is `!raw.trim()` of the decoded line: only JavaScript white space and line terminators.
func jsBlank(b []byte) bool {
	for len(b) > 0 {
		r, n := utf8.DecodeRune(b)
		if r == utf8.RuneError && n <= 1 || !jsSpace(r) {
			return false
		}
		b = b[n:]
	}
	return true
}

func jsSpace(r rune) bool {
	switch r {
	case '\t', '\n', '\v', '\f', '\r', ' ', 0xa0, 0x1680, 0x2028, 0x2029, 0x202f, 0x205f, 0x3000, 0xfeff:
		return true
	}
	return r >= 0x2000 && r <= 0x200a
}

// incompleteTail is the length of an incomplete but valid UTF-8 sequence at the end of b, which TextDecoder in stream
// mode holds back (0 when the end is complete or already invalid).
func incompleteTail(b []byte) int {
	for n := 1; n <= 3 && n <= len(b); n++ {
		i := len(b) - n
		c := b[i]
		if c < 0x80 {
			return 0
		}
		if c < 0xc0 {
			continue // a continuation byte: its lead is further back
		}
		need := 0
		switch {
		case c >= 0xc2 && c <= 0xdf:
			need = 2
		case c >= 0xe0 && c <= 0xef:
			need = 3
		case c >= 0xf0 && c <= 0xf4:
			need = 4
		default:
			return 0
		}
		if n >= need {
			return 0
		}
		lo, hi := byte(0x80), byte(0xbf)
		switch c {
		case 0xe0:
			lo = 0xa0
		case 0xed:
			hi = 0x9f
		case 0xf0:
			lo = 0x90
		case 0xf4:
			hi = 0x8f
		}
		if n >= 2 && (b[i+1] < lo || b[i+1] > hi) {
			return 0
		}
		return n
	}
	return 0
}
```

```go
// Start sends the plan's request and returns the provider's answer once its headers are in, its body unread, or Why the
// call failed. Closing the answer's body ends the call. ctx ends when the client goes away. The 120 s limit covers
// the headers only; the body has none, as in JS.
func (u *Upstream) Start(ctx context.Context, p *Plan) (*http.Response, string) {
	ctx, cancel := context.WithCancel(ctx)
	var timedOut atomic.Bool
	timer := time.AfterFunc(u.timeout, func() { timedOut.Store(true); cancel() })
	fail := func(why string) (*http.Response, string) {
		timer.Stop()
		cancel()
		return nil, why
	}
	current := p.URL
	for hop := 0; hop <= maxRedirects; hop++ {
		req, err := http.NewRequestWithContext(ctx, http.MethodPost, current, &onceBody{b: p.Body})
		if err != nil {
			return fail("fetch failed")
		}
		req.ContentLength = int64(len(p.Body))
		req.GetBody = func() (io.ReadCloser, error) { return &onceBody{b: p.Body}, nil } // p.Body, read when called
		req.Header = p.Header.Clone()
		resp, err := u.client.Do(req)
		if err != nil {
			if timedOut.Load() {
				return fail("timed out")
			}
			return fail(ErrorCode(err))
		}
		loc := resp.Header.Get("Location")
		if resp.StatusCode < 300 || resp.StatusCode >= 400 || loc == "" {
			timer.Stop() // the answer has started: the body has no time limit, as in JS
			resp.Body = &cancelBody{ReadCloser: resp.Body, cancel: cancel}
			return resp, ""
		}
		_ = resp.Body.Close()
		from, _ := url.Parse(current)
		next, err := from.Parse(loc)
		if err != nil {
			return fail("fetch failed")
		}
		if origin(next) != origin(from) {
			return fail("refused a redirect from " + from.Host + " to " + next.Host +
				"; credentials are not forwarded to another host")
		}
		current = next.String()
	}
	return fail("too many redirects")
}

// Call sends the plan's request and reads the whole answer.
func (u *Upstream) Call(ctx context.Context, p *Plan) Result {
	resp, why := u.Start(ctx, p)
	if why != "" {
		return Result{Why: why}
	}
	body, err := io.ReadAll(resp.Body)
	_ = resp.Body.Close()
	if err != nil && ctx.Err() != nil {
		return Result{Status: resp.StatusCode, Body: body, Why: "client gone"}
	}
	return Result{Status: resp.StatusCode, Body: body}
}

// onceBody is a request body that lets go of its bytes once they are read or the request is done with it, so a long
// stream does not keep its prompt alive (P4c Decision 11). Read and Close may run at once (net/http's rule).
type onceBody struct {
	mu sync.Mutex
	b  []byte
}

func (o *onceBody) Read(p []byte) (int, error) {
	o.mu.Lock()
	defer o.mu.Unlock()
	if len(o.b) == 0 {
		o.b = nil
		return 0, io.EOF
	}
	n := copy(p, o.b)
	o.b = o.b[n:]
	if len(o.b) == 0 {
		o.b = nil
	}
	return n, nil
}

func (o *onceBody) Close() error {
	o.mu.Lock()
	o.b = nil
	o.mu.Unlock()
	return nil
}

// cancelBody ends the call when the answer's body is closed.
type cancelBody struct {
	io.ReadCloser
	cancel context.CancelFunc
}

func (c *cancelBody) Close() error {
	err := c.ReadCloser.Close()
	c.cancel()
	return err
}
```
