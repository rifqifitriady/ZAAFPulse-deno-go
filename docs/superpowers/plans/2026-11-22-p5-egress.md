# P5: the Go egress proxy and the network lock-down — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Every outbound connection of the Deno control plane goes through a recording, allow-listing egress endpoint
in `zaafpulse-gw`, each caller class behind its own switch, and an opt-in launch narrows Deno's net grant to loopback,
proven by a test that a direct outbound connect is denied.

**Architecture:** `gw/egress` serves a token-protected forward endpoint and a `CONNECT` tunnel on `127.0.0.1:0`; each
request is checked (allow-list, public mode), made with the engine's client settings, and recorded as an
`egress.event` through the outbox. `lib/egress.js` is the one client: unconfigured it is plain `fetch`/`net.connect`;
configured by `server.js` it sends each class on `go` to the endpoint. The lock-down is a computed `--allow-net` on the
`deno run` launch line.

**Tech Stack:** Go (module `gw/`, `GOTOOLCHAIN=local`, standard library only). Node 24 and Deno 2.9 (CommonJS,
`node:` built-ins only, `node:test`).

```go
package egress // gw/egress

const TokenLabel = "zaafpulse egress v1"
func DeriveToken(frontToken string) string // hex HMAC-SHA256(frontToken, TokenLabel)

type Rule struct{ Host string; Port int } // Host: name, address or "*.suffix"; Port 0 = any
type Mode string                           // "report" | "enforce"
type Policy struct{ Allow []Rule; Mode Mode }
func (p *Policy) Allows(host string, port int) bool

func IsPrivate(ip net.IP) bool // lib/net.js isPrivateAddress, proven by gw/testdata/egress/private.json

type Record struct { // the egress.event body
	TS int64; Purpose, Method, Scheme, Host string; Port int; Status int /*0: none*/
	Outcome string /*ok|error|refused|would-refuse|checked*/; Error string; BytesOut, BytesIn int64; MS float64
	Via string /*proxy|tunnel|engine*/
}

type Server struct{ /* token, policy (atomic), client, record func(Record), now */ }
func New(client *http.Client, record func(Record)) *Server // client: a copy of the engine's (proxy env, roots, 10 s connect)
func (s *Server) SetToken(t string)
func (s *Server) SetPolicy(p Policy)
func (s *Server) Handler() http.Handler                    // "/" forward, "/check", CONNECT
func (s *Server) Listen() (port int, err error)            // 127.0.0.1:0
func (s *Server) Close(grace time.Duration)
func RecordingTransport(rt http.RoundTripper, purpose string, record func(Record)) http.RoundTripper // via "engine"

// Error codes (X-ZP-Egress-Error): ECONNREFUSED ENOTFOUND ETIMEDOUT ECONNRESET CERT_INVALID EPROTO
// EGRESS_REFUSED EGRESS_PRIVATE EGRESS_REDIRECTS EGRESS_REDIRECT
```

## Plan deviations

- Task 1: optional Go fields use `omitzero`, not `omitempty` (`gw/ipc/shape.go` treats only `omitzero` as optional).
  `EgressConfig.Classes` is `map[string]EgressSwitch` (a string type that accepts only `direct|check|go`) instead of
  `map[string]string`, so the Go decode refuses the same invalid fixture the schema refuses.
- Task 1: fixtures are named `valid-ok.json`, `valid-refused.json`, `valid-tunnel.json`, `valid-engine.json` (both
  fixture tests require the `valid`/`invalid` prefix).
- Task 1: `recoverMarks` also reads the tail of `.data/egress.jsonl` (and `.1`), and `localPaths` names it
  (`egressFile`): an egress line carries the stream's mark like the other stores, so a restart must see it.
- Task 1: a `refused` record's governance entry is written first and carries no `ipc` mark; the egress line, written
  after it, carries the mark. A failed egress append after the entry means the resend writes the entry again (at least
  once); a stored egress line is never without its entry. The entry matches the `audit.event` governance shape as
  given (no adaptation needed).
- Task 2 (from its report): `egress.New(client, record)` copies the given client's `*http.Transport` (a client whose
  transport is not one gets net/http's defaults) and turns Go's gzip on; `/check` takes the call's method from an
  optional `X-ZP-Egress-Method` (default GET); a request without `X-ZP-Egress-Purpose` is recorded as `unspecified`;
  public mode connects without the proxy environment (the address checked at connect must be the target's); a caller
