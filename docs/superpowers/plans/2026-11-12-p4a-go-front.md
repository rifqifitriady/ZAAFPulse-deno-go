# P4a Go Front Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The Go gateway (`zaafpulse-gw`) holds the main port in front of the Deno server when `gateway.engine` is `"front"`, forwards every request to the server's internal port with a signed `X-ZP-Client` header that names the real client, and the server falls back to serving the port itself when the gateway cannot run; `"js"` (the default) behaves exactly as before.

**Architecture:** The Deno server keeps one request handler. In `front` mode its `http(s).Server` does not listen; an internal listener on `127.0.0.1:0` (`lib/front/internal.js`, Task 3) checks each request's `X-ZP-Client: <ip> <port> <tls> <hmac>` header against the `frontToken`, stores the client for the six peer readers (`lib/front/client.js`) and hands the request to that server. The server starts the gateway through the P3 supervisor (`lib/ipc/supervisor.js`), which pushes a `config.push` with a new optional `front` section and a `secrets.handoff` with a new optional `frontToken`. The gateway (`gw/front`, standard library `httputil.ReverseProxy`) opens the main port on `ready`, overwrites `X-ZP-Client` on every forwarded request, and exits with a fixed code and a `fatal: ` line when a restart cannot help; the supervisor then enters `failed` and `lib/front` makes the server listen on the main port itself (`fallback`). The P3 entry conditions E1–E11 are closed first (Task 1 in Go, merged; Task 2 in JS).

**Tech Stack:** Deno 2.9.8 and Node 24 (CI 24.21.0; dual runtime until P7), CommonJS, `node:test`, Go 1.27.3 standard library only (`net/http/httputil`, `crypto/tls`, `syscall`), JSON Schema draft 2020-12 subset (`lib/ipc/schema.js`), GitHub Actions pinned by SHA, prettier 3 (printWidth 120) on JS files that were clean, `gofmt` on Go files.

## Spec deviations

1. **The client travels in a signed header, not a connection preamble (D3).** The probe failed on Deno (F2), and Go's pool shares upstream connections between clients. Task 3 built the spec's fallback: `X-ZP-Client: <ip> <port> <tls> <hmac>` on every request, checked by the internal listener. Task 4 Step 1 updates spec D3 and the T4 row to say so.
2. **Forwarding headers pass through; they are not removed (D2).** The server reads their presence as "a proxy is in front" (F6). If Go removed them, a proxy in front of a no-sign-in install would no longer be refused, and a proxied caller would reach `/v1/traces`. Go forwards `X-Forwarded-*`, `Forwarded`, `X-Real-IP` and `Via` exactly as the client sent them and adds none (F3: it restores the four `Rewrite` drops). `ZAAFPULSE_TRUST_PROXY` keeps its meaning without being passed to Go, and `front` carries no trust setting.
3. **Six peer readers, not four (D3), and the `Origin` rule is not one of them (F5).** Task 3 moved all six to `peerAddress()` / `peerEncrypted()`. Because the `Origin` rule reads only the header, the auth mode is what keeps front mode safe; Task 5 adds a second guard (H1): without sign-in, a client Go names from another machine is refused (`peerMayConnect`), even when it writes `Host: 127.0.0.1`. `pickMode` and `SERVER_MODE` keep reading `HOST`, the public listen host Go holds, never the internal `127.0.0.1`.
4. **One contract case is relaxed in front mode (F4), by the coordinator's call (no owner question).** Go's `net/http` refuses a malformed request target before any handler, so its plain-text 400 cannot be changed without replacing the server. The case `GET /v1/models/{id} with broken URL encoding: 400` keeps asserting status 400 and, only under `ZP_ENGINE=front`, accepts Go's body `400 Bad Request` as well as the JSON message. No real client sends such a request.
5. **`runScope` does not reach the single-file binary (D7, F9).** P4a grants the gateway binary to `deno run` launches (the service install, the tests, the preview). `front` mode in a compiled binary needs the gateway shipped beside it and a baked grant: P6 (open question 2). The compiled binary keeps working in the default `js` mode.
6. **`/api/gateway/status` collides with the admin-route pattern (F7).** The route is matched before it. It is owner-only: it is not added to `lib/users/policy.js VIEWER_READS`, so the existing role check refuses everyone else, and the Overview chip stays hidden for them.
7. **E3: no raw usage writer exists (F8).** The ingest builds its own `createUsage` on the same `gateway-usage.jsonl`, as `lib/ipc/local.js` does, and uses the server's raw governance, MCP audit and trace stores. A second `createGovernanceAudit` on the same folder (what `local.js` does in tests) would fork the HMAC chain, so it is not used in the server.
8. **E8 needs more than the exit code.** On Windows a hard kill (`taskkill /F`, `TerminateProcess`) exits 1 with no signal, the same code as a damaged outbox, and must be restarted. The supervisor enters `failed` on 1, 2, 4 or 5 only with the gateway's `fatal: ` stderr line (or when this side refused the hello). Task 1 does not print that prefix (F11); Task 2 adds it (`exitWith`).
9. **E5: the schemas are listed one by one (F10)**, and "a test on the compiled binary" is the `doctor` line `Gateway IPC  v1, 15 schemas`, checked by `scripts/smoke-binary.js` in the six-target CI job.
10. **The 2 s first-request close of Task 3's listener is lengthened in front mode (F15).** `createFront` passes `firstRequestMs: 130000` (longer than Go's 120 s idle timeout), so Go always closes a spare pooled connection first; the default stays 2 s.
11. **Spec line references** are a few lines off at 464daf6: `gateway.handle` is at `server.js:1497` (spec 1511), the trace check at `server.js:1483-1486` (spec 1493), the loopback `Origin` rule at `lib/auth.js:165` (spec 160).

## Spec ambiguities resolved by this plan

1. **What P4a pushes.** Every route is on `js`, so `config.push` carries an empty gateway section (`providers: []`, `routes: []`, guardrails all `off`, empty defaults, `keys: []`, `pricing: {}`) plus `front`; `secrets.handoff` carries `providers: []`, `mask: []` and `frontToken`. The config.json-to-config.push converter comes with the first `go` route (P4b).
2. **A `go` engine** is valid in the schema (P4b needs it) and refused twice in P4a: `lib/front frontSection` throws before anything is pushed, and the gateway exits 2 (`ExitRefused`) with a `fatal: ` line if one arrives.
3. **Exit 4** covers any failure to open the main port: in use, permission refused, or TLS files that do not load; the `fatal: ` line names which.
4. **"5 restarts within 60 s":** the gateway may be restarted 5 times within 60 s; the exit that would need a sixth is the `failed` state (`maxRestarts: { count: 5, windowMs: 60000 }`).
5. **"A later reload":** a change of `config.json`'s `gateway` section (server.js `configChanged`). In `front` mode it pushes a new config generation; in `fallback` mode it closes the server's main listener and tries `front` again (owner question 2). `zaafpulse service restart` also tries again.
6. **"Raises a dashboard alert":** `status().alert` is `true` in `fallback`, and the Overview chip turns red with the reason; the server logs `gateway failed: <reason>; serving on Deno`.
7. **One upstream pool, a header per request.** The client header is set on each forwarded request, so the front shares one `http.Transport` (idle timeout 120 s) between clients.
8. **Where the gateway binary is:** `ZAAFPULSE_GW_BIN`; else beside the executable in a single-file build; else `gw/bin/zaafpulse-gw[.exe]` in the source folder (`npm run gw:build`). `gw/bin/` is ignored by git.
9. **TLS** is terminated by Go with HTTP/1.1 only, as the server's own `https` server answers today.
10. **The Go side of the mark file (E4)** needs nothing: the control plane writes `.data/ipc-marks.json` in the session's `beforeAck` hook, after the store and before the ack; a failed write holds that ack back (the next flush retries).
11. **`Expect: 100-continue`** gets its `100 Continue` only after the client header checks out (`checkContinue` in the internal listener, F14); a bad header closes the connection without a byte.
12. **`session.exited`** resolves on the child's `'close'` (stderr read to the end, so the `fatal: ` line is known), or 2 s after `'exit'` if a pipe stays open.

func hasFatalLine(log string) bool {
	for line := range strings.Lines(log) {
		if strings.HasPrefix(line, "fatal: ") {

// The environment the gateway process gets (P4a spec E7): the data folder, PATH, the home folder and, on Windows, what
// the OS needs (SystemRoot, TEMP, TMP). Nothing else: provider keys in environment variables reach the gateway only
// through secrets.handoff.

/**
 * @param {Record<string, string | undefined>} env the control plane's environment
 * @param {string} dataDir the data folder (lib/platform.js dataDir())
 * @param {string} [platform]
 * @returns {Record<string, string>}
 */
function gwEnv(env, dataDir, platform = process.platform) {
  const win = platform === 'win32';
  // Windows names are case-insensitive (Path, SYSTEMROOT): look them up that way, pass them under one spelling.
  const get = (name) => {
    if (env[name] !== undefined) return env[name];
    if (!win) return undefined;
    const k = Object.keys(env).find((x) => x.toUpperCase() === name.toUpperCase());
    return k === undefined ? undefined : env[k];
  };
  const out = { ZAAFPULSE_DATA: dataDir };
  for (const name of ['PATH', 'HOME', 'USERPROFILE', ...(win ? ['SystemRoot', 'TEMP', 'TMP'] : [])]) {
    const v = get(name);
    if (typeof v === 'string' && v !== '') out[name] = v;
  }
  return out;
}

module.exports = { gwEnv };

// event stream that the control plane stored and is about to acknowledge. It is written (a temp file, then rename)
// before each ack is sent and after the events it covers were stored, so it never runs ahead of the stores. On start,
// the larger of it and the stores' tails (lib/ipc/marks.js recoverMarks) is the mark, so a mark that fell out of the
// tail window is not lost.

### D3. The client header: no request looks local by accident

(Revised 2026-11-12 after the Task 3 probe; the first version used a connection preamble.) The probe failed: on Deno
2.9.8 an `http.Server` handed a socket with `emit('connection')` answers the first request on that connection and not
the next one, and Go's connection pool shares one upstream connection between clients, which a per-connection preamble
cannot describe. So Go names the client in a header on **every** request it forwards:

```
X-ZP-Client: <client-ip> <client-port> <tls:0|1> <hmac>
```

`<hmac>` is the lowercase hex HMAC-SHA256 of the exact text `"<client-ip> <client-port> <tls>"`, keyed with the
`frontToken`'s hex text as UTF-8 bytes; the value is at most 256 bytes. Go overwrites any `X-ZP-Client` the client sent
(never appends). Deno's internal listener (`lib/front/internal.js`) is an `http.Server` on `127.0.0.1:0`. For each
request it:
1. checks the header with `parseClientHeader` (`lib/front/client.js`, constant-time compare) and closes the connection
   without a reply when it is missing, malformed or not signed with this token;
2. stores the client on the request, removes the header, and hands the request to the dashboard server's own handler.

The six checks that read the peer use `peerAddress()` / `peerEncrypted()`: `clientKey`, `Secure` cookies,
`isTraceCaller` (the `/v1/traces` rule), `isLocalRequest`, the gateway's `publicBase` and otel's `url.scheme`. The
loopback `Origin` rule reads only the `Origin` header, so the auth mode is what keeps front mode safe: `pickMode` and
the host checks keep reading the public listen host (`ZAAFPULSE_HOST`), and without sign-in a client Go names from
another machine is refused (`peerMayConnect`). A request on the main port in js mode never carries a stored client, so
a client that sends the header itself changes nothing.

  the server reads their presence as "a proxy is in front", and `ZAAFPULSE_TRUST_PROXY=1` keeps its meaning (a proxy
  in front of Go).

package front

import (
	"crypto/hmac"
	"crypto/sha256"
	"encoding/hex"
	"net"
	"strings"
)

// ClientHeader is the header the front puts on every request it forwards (P4a spec D3, header design): the client's
// address and port, whether it came over TLS, and an HMAC that proves the front wrote it. The control plane's internal
// listener (lib/front/client.js parseClientHeader) refuses a request without a valid one.
const ClientHeader = "X-Zp-Client"

// ClientValue is "<ip> <port> <tls:0|1> <hmac>", where hmac is the lowercase hex HMAC-SHA256 of "<ip> <port> <tls>"
// keyed with the frontToken's hex text as bytes. remoteAddr is http.Request.RemoteAddr ("ip:port", "[ipv6]:port").
// An IPv6 zone is dropped (the control plane refuses one); an IPv4-mapped address is written as IPv4.
func ClientValue(token, remoteAddr string, tls bool) string {
	host, port, err := net.SplitHostPort(remoteAddr)
	if err != nil {
		host, port = remoteAddr, "0"
	}
	host, _, _ = strings.Cut(host, "%")
	if ip := net.ParseIP(host); ip != nil {
		host = ip.String()
	}
	t := "0"
	if tls {
		t = "1"
	}
	text := host + " " + port + " " + t
	mac := hmac.New(sha256.New, []byte(token))
	mac.Write([]byte(text))
	return text + " " + hex.EncodeToString(mac.Sum(nil))
}

// the main port (TLS when configured) and forwards every request to the control plane's internal port on 127.0.0.1,

	engines  atomic.Pointer[map[string]string]
	inflight atomic.Int64
}

// Listen loads the TLS files (when set) and opens the main port. ErrAddrInUse when the port is taken.
func Listen(cfg Config, logger *log.Logger) (*Server, error) {
	var tlsCfg *tls.Config
	if cfg.CertFile != "" {
		cert, err := tls.LoadX509KeyPair(cfg.CertFile, cfg.KeyFile)
		if err != nil {
			return nil, fmt.Errorf("front: TLS: %w", err)
		}
		// HTTP/1.1 only, as the control plane's own https server answers today.
		tlsCfg = &tls.Config{Certificates: []tls.Certificate{cert}, NextProtos: []string{"http/1.1"}, MinVersion: tls.VersionTLS12}
	}
	ln, err := net.Listen("tcp", net.JoinHostPort(cfg.Host, strconv.Itoa(cfg.Port)))
	if err != nil {
		if addrInUse(err) {
			return nil, fmt.Errorf("%w: %s:%d", ErrAddrInUse, cfg.Host, cfg.Port)
		}
		return nil, fmt.Errorf("front: listen on %s:%d: %w", cfg.Host, cfg.Port, err)
	}
	if tlsCfg != nil {
		ln = tls.NewListener(ln, tlsCfg)
	}
	s := &Server{cfg: cfg, ln: ln}
	s.SetEngines(cfg.Engines)
	target := &url.URL{Scheme: "http", Host: net.JoinHostPort("127.0.0.1", strconv.Itoa(cfg.Upstream))}
	s.proxy = &httputil.ReverseProxy{
		Rewrite: func(pr *httputil.ProxyRequest) {
			pr.SetURL(target)
			pr.Out.Host = pr.In.Host
			// Rewrite drops these four from Out before it runs. The control plane reads them as the client sent them
			// (its proxy checks look for their presence), so they go through unchanged; the front adds none.
			for _, h := range []string{"X-Forwarded-For", "X-Forwarded-Host", "X-Forwarded-Proto", "Forwarded"} {
				if v, ok := pr.In.Header[h]; ok {
					pr.Out.Header[h] = append([]string(nil), v...)
				}
			}
			// Set replaces any X-Zp-Client the client sent.
			pr.Out.Header.Set(ClientHeader, ClientValue(cfg.Token, pr.In.RemoteAddr, pr.In.TLS != nil))
		},
		Transport: &http.Transport{
			DisableCompression:  true, // never add Accept-Encoding: the client's headers go as sent
			MaxIdleConnsPerHost: 64,
			// Shorter than the internal listener's keep-alive (130 s): the front always closes an idle connection first.
			IdleConnTimeout: 120 * time.Second,
		},
		FlushInterval: -1, // SSE and chunked bodies pass through at once
		ErrorLog:      logger,
		ErrorHandler: func(w http.ResponseWriter, r *http.Request, err error) {
			if r.Context().Err() != nil {
				return // the client is gone
			}
			logger.Printf("front: %s %s: %v", r.Method, r.URL.Path, err)
			w.Header().Set("Content-Type", "application/json")
			w.Header().Set("Retry-After", "2")
			w.WriteHeader(http.StatusBadGateway)
			_, _ = w.Write([]byte(`{"error":"the control plane is not answering"}`))
		},
	}
	s.srv = &http.Server{
		Handler:           s,
		ReadHeaderTimeout: 10 * time.Second,
		IdleTimeout:       120 * time.Second,
		ErrorLog:          logger,
	}
	return s, nil
}

// Serve answers on the main port until Shutdown or Close (then it returns nil).
func (s *Server) Serve() error {
	if err := s.srv.Serve(s.ln); !errors.Is(err, http.ErrServerClosed) {
		return err
	}
	return nil
}

// Addr is the main port's address.
func (s *Server) Addr() net.Addr { return s.ln.Addr() }

// Inflight is the number of requests being answered (health.inflight).
func (s *Server) Inflight() int64 { return s.inflight.Load() }

// SetEngines replaces the engine of each route class (a later config.push).
func (s *Server) SetEngines(m map[string]string) {
	c := make(map[string]string, len(m))
	for k, v := range m {
		c[k] = v
	}
	s.engines.Store(&c)
}

func (s *Server) engine(class string) string {
	if class == "" {
		return "js"
	}
	if e, ok := (*s.engines.Load())[class]; ok {
		return e
	}
	return "js"
}

	if err != nil {
		_ = s.srv.Close()
	}
	return err
}

		_, _ = w.Write([]byte(`{"error":"the go engine is not available in this gateway"}`))

	}

	}
	return -1
}

  host,
  port,

  mainServer,
  bin,
  env,

  ingest,

  async function listenMain(waitMs) {
    const end = Date.now() + waitMs;
    for (;;) {
      try {
        await new Promise((resolve, reject) => {
          const onError = (err) => {
            mainServer.off('listening', onListening);
            reject(err);
          };
          const onListening = () => {
            mainServer.off('error', onError);
            resolve();
          };
          mainServer.once('error', onError);
          mainServer.once('listening', onListening);
          mainServer.listen(port, host);
        });
        return;
      } catch (err) {
        if (err.code !== 'EADDRINUSE' || Date.now() >= end) throw err;
        await new Promise((r) => setTimeout(r, 100));
      }
    }
  }

      env,
      cpVersion,
      ingest,

      log,

        snapshot: () => ({ budgets: [], keyCenter: {} }),
      },
      maxRestarts: { count: 5, windowMs: 60000 },
      onReady: () => serving('front'),
      onFailed: (why) => {
        fallback(why).catch(onListenError);
      },
      ...supOpts,
    });
    sup.start();

    if (mode !== 'front') return;
    mode = 'fallback';
    reason = why;

    if (inner) await inner.close();
    inner = null;
    await listenMain(waitPortMs);

        serving('js');

const pct = (sorted, p) => sorted[Math.min(sorted.length - 1, Math.floor((p / 100) * sorted.length))];

function get(agent, port, p) {
  return new Promise((resolve, reject) => {
    const req = http.get({ host: '127.0.0.1', port, path: p, agent }, (res) => {
      res.resume();
      res.on('end', () => (res.statusCode === 200 ? resolve() : reject(new Error(`${p}: ${res.statusCode}`))));
    });

async function measure(config) {
  const s = await startServer({ runtime: RUNTIME, config });
  const port = Number(new URL(s.base).port);
  const agent = new http.Agent({ keepAlive: true, maxSockets: 1 });
  try {
    for (let i = 0; i < 200; i++) await get(agent, port, PATHS[i % PATHS.length]);
    const ms = [];
    for (let i = 0; i < COUNT; i++) {
      const t = performance.now();
      await get(agent, port, PATHS[i % PATHS.length]);
      ms.push(performance.now() - t);
    }
    ms.sort((a, b) => a - b);
    const r3 = (x) => Math.round(x * 1000) / 1000;
    return { p50: r3(pct(ms, 50)), p99: r3(pct(ms, 99)), mean: r3(ms.reduce((a, b) => a + b, 0) / ms.length) };
  } finally {
    agent.destroy();
    await s.stop();
  }
}

## Differences from the spec

1. The client travels in a signed header, not a connection preamble: the probe failed on Deno 2.9.8 (an `http.Server`
   handed a socket with `emit('connection')` answers only the first request on it), and Go's pool shares upstream
   connections. Spec D3 was updated.
2. Forwarding headers pass through the gateway unchanged; the server reads their presence as "a proxy is in front".
3. Six peer readers, not four; the `Origin` rule reads only the header, so the auth mode and the local-only peer guard
   keep front mode safe.
4. One contract case, `GET /v1/models/{id} with broken URL encoding: 400`, accepts Go's own plain-text `400 Bad
   Request` in front mode (status unchanged). Go's `net/http` refuses such a request line before any handler; no real
   client sends one.
5. `front` in the single-file binary needs the gateway shipped beside it and a baked run grant (P6); `deno run`
   launches get the grant from `runScope`.
6. The supervisor's `failed` state needs the gateway's `fatal: ` line with exit 1, 2, 4 or 5: a hard kill on Windows
   exits 1 too and is restarted.
7. The internal listener waits 130 s for a connection's first request in front mode (Go's idle pool), 2 s otherwise.
