# P4g: `/mcp` `tools/call` and provider auth on the Go engine (slices S9, S10) — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The go engine serves `/mcp` `tools/call` (key, rate limit, both guardrail checks, line, spans, reply; the tool
itself runs in the control plane over the internal port) and calls OAuth2 and Google service-account providers with
tokens it refreshes itself (`gw/provauth`), with the 401 replay and the background refresh, each behind its own switch
(`mcp`, `provider-auth`) with shadow and switch-rule records, proven byte for byte by fixtures from the real JS.

**Architecture:** Pure planners and answer builders in `gw/engine` (`mcp.go`, `auth.go`) proven by route-level fixtures
that two new generators write by running `createGateway` in process (`gen-mcp.js`, `gen-auth.js`). Serving reuses the
P4b–P4f sequence (`Take` → checks → call → line → reply → spans). Tokens live in an engine-wide registry outside the
state generations; `Upstream.Start` puts the token on the request and replays once after a 401. The `provider-auth`
switch copies the token saver's `token-saver` switch (rtk spec D13/D14).

**Tech Stack:** Go (module `gw/`, `GOTOOLCHAIN=local`, standard library only); `gw/provauth`, `gw/guard`,
`gw/translate/jsv`. Node 24 and Deno 2.9 for generators and the contract suite (CommonJS, `node:` built-ins only).

//   Tool     string        params.name
//   ToolArgs *Value        params.arguments ({} when absent or null)
//   ToolTier string        "private" for acc_*, else "external"

func (s *State) PlanMCP(r *Request, now int64) Plan
// CheckToolArgs runs the arguments check when p.Policy is set. refusal != nil: the reply to write and its line (rec
// non-nil). Otherwise args is the JSON text to send the tool (JSON.stringify of the checked arguments) and hits the
// arguments' hits (for the result step).
func (s *State) CheckToolArgs(p *Plan, ms float64) (args []byte, st ToolState, refusal *Answer)
// ToolReply builds the reply from the tool endpoint's answer ({"r": …} or {"thrown": true}; nil body: the call failed)
// and the line JS writes (Answer.NoLine when none).
func (s *State) ToolReply(p *Plan, st ToolState, endpoint []byte, ms float64) Answer

type ToolState struct { Hits []guard.Hit; Action string; Failed bool } // what the arguments check found

func (e *Engine) SetTools(call func(ctx context.Context, body []byte) (status int, answer []byte, err error))

// auth.go
type Tokens struct{ /* registry */ }
func NewTokens(client *http.Client, state func() *State, clock provauth.Clock) *Tokens
func (t *Tokens) Source(p *ipc.ProviderConfig) *provauth.Cached // nil for a key provider
func (t *Tokens) Tick(now time.Time)                            // the background refresh pass (the ticker calls it every 60 s)
func (t *Tokens) Run(stop <-chan struct{})                      // the 60 s ticker
func (u *Upstream) Client() *http.Client                        // the provider client, for provauth

package provauth
func (c *Cached) Expiry() (time.Time, bool) // the cached token's expiry; false when none
